# ai-powered-projects

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

To type check:

```bash
bun check
```

Run `bun fmt` to format the code.

This project was created using `bun init` in bun v1.4.4. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

This project also used [Husky](https://typicode.github.io/husky/) to automate the Git workflow.

To install:

```bash
bun add --dev husky
```

To initialize :

```bash
bunx husky init
```
